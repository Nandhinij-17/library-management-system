# LIBRARY MANAGEMENT SYSTEM
## MERN Stack Project Report

### 1. Objective
To develop a responsive web-based Library Management System using MongoDB, Express.js, React.js and Node.js. The system provides CRUD operations for managing library books.

### 2. Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios
- HTML5 / CSS3
- Vite

### 3. Main Modules
1. Dashboard
2. Add Book
3. View Books
4. Search Books
5. Update Book
6. Delete Book
7. Availability Status
8. Form Validation

### 4. Workflow
User → React Frontend → Axios → Express REST API → Mongoose → MongoDB

### 5. CRUD Operations
- Create: Add a new book.
- Read: Display all books and search results.
- Update: Edit book details and status.
- Delete: Remove a book after confirmation.

### 6. Validation
Required fields are validated on the frontend and through Mongoose schema validation on the backend. ISBN values are unique.

### 7. Testing
The application can be tested for:
- Adding valid and invalid books
- Searching books
- Editing book details
- Changing availability
- Deleting books
- Empty collection handling
- MongoDB connection
- API error handling

### 8. Expected Outcome
A working MERN-based Library Management System with documented workflow, CRUD functionality, validation and responsive UI.

### 9. Conclusion
The project demonstrates practical implementation of full-stack web development concepts using the MERN stack.
